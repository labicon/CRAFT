The 'state' variable is a dictionary that contains:
"box_pos": tensor (num_envs, num_agents, 2) for the center coordinates of the box.
"box_yaw": tensor (num_envs, num_agents, 1) for the box's yaw angle in radians [-pi, pi]. Note that for each agent, the value is identical.
"agent_pos": tensor (num_envs, num_agents, 2) for the agent's xy coordinates.
"agent_yaw": tensor (num_envs, num_agents, 1) for the agent's yaw angle.
"target_pos": tensor (num_envs, num_agents, 2) for the target xy coordinates. Note that for each agent, the value is identical. The target is randomized each episode: x in [2.0, 3.5], y in [-1.5, 1.5].

The 'action' variable is a tensor (num_envs, num_agents, 3) for (x linear velocity command, y linear velocity command, yaw angular velocity command)
Note that the coordinates in the state are in the global frame and the coordinates of the action are in the agent's local frame.

You can use helper functions to calculate reward.
self._box_forward_movement(state, action): returns tensor (num_envs, num_agents) for cumulative box movement in x direction since episode reset
self._box_distance_to_target(state, action): returns tensor (num_envs, num_agents) for the Euclidean distance from the box center to the target position
self._box_movement_toward_target(state, action): returns tensor (num_envs, num_agents) for cumulative reduction in distance from box to target since episode reset (positive means closer)
self._box_y_deviation(state, action): returns tensor (num_envs, num_agents) for the absolute y-coordinate of the box
self._agents_distance_to_box(state, action): returns tensor (num_envs, num_agents) for the distance between each agent and the box center
self._success_evaluation(state, action): returns tensor (num_envs, num_agents) which returns 1 if the box is within 0.5m of the target position and 0 otherwise
self._head_box_collision_flag(): returns tensor (num_envs, num_agents), 1 if head links collide with box and 0 otherwise
self._non_head_box_collision_flag(): returns tensor (num_envs, num_agents), 1 if non-head links collide with box and 0 otherwise
self._check_reward_shape(reward): returns reshaped reward tensor to avoid index error
self._agent_yaw_error_to_box(state, action): returns tensor (num_envs, num_agents) for the absolute angular error (radians, [0, pi]) between each agent's yaw and the box's yaw. Use this to reward yaw alignment for effective pushing.
self._box_yaw_to_target(state, action): returns tensor (num_envs, num_agents) for the absolute angular error (radians, [0, pi]) between the box's current yaw and the direction from the box toward the target. Use this to reward the box being oriented toward the target for steering.

The box starts at yaw = 0 (aligned with global axes). The box is elongated along the y-axis (1.0m × 3.0m).
Both agents push the same face of the box (the back face). For efficient pushing, both Agent 0 (blue) and Agent 1 (green) should align their yaw to match the box's current yaw angle.
To steer the box toward an off-center target, agents must coordinate to induce box yaw rotation while maintaining alignment.
For this task, include reward terms that encourage pushing with head links and penalize non-head collisions with the box.
