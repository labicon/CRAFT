<<Environment_Description>>

Varaibles you can use for curriculum descriptions are
- xy coordinate of the goal position
- xy coordinate of the obstacle position
- xy coordinate of each agent
- yaw angle of each agent

These are the rules that you have to consider when writing a curriculum
(1) You cannot change start position of agents, obstacles, and target position.
(2) You cannot change the number of agents or obstacles.
(3) You should consider all agents in the environment.
