You should write a reward function for the given task using useful variables from the environment.
Your reward function is part of curriculum learning which consists of learning a sequence of different tasks.
You will be given a description of past tasks, reward code for past tasks, and the current task description.

Your gpt_reward(self, state, action) function's output should consist of three items:
    (1) the total reward, a tensor shaped (self.num_envs, self.num_agents)
    (2) a dictionary of each individual reward component where keys are names of reward components and values are the mean of each reward
    (3) the maximum possible reward that is used to normalize the reward, a scalar

Some helpful tips for writing reward function code:
(1) Use torch functions to write the reward function. torch is already imported as torch. Do not import additional libraries.
(2) You may put higher weight on the reward for the current task, but also include rewards from past tasks to avoid forgetting.
(3) Total reward must stay within [0, 1]. Always scale the reward to have a maximum of 1. 
(4) Only use provided helper functions. Do not use state and action variables without helper functions.
(5) Do not change other predefined parts in the code. 
(6) Make sure that the returned reward shape is (self.num_envs, self.num_agents). If you are not sure, verify it using the self._check_reward_shape function.
