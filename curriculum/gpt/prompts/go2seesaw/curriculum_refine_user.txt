Varaibles you can use for curriculum descriptions are
- xyz position of the target that agent should climb up using seesaw
- xy position of the seesaw start where robot should enter through
- xy position of the seesaw end where close to the target platform
- xyz position of each agent

These are the rules that you have to consider when writing a curriculum
(1) You cannot change start position of agents and seesaw.
(2) You cannot change the number of agents.
